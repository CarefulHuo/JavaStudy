### 应用场景
1. Java 中的注解
2. Spring、Mybatis 等框架都大量使用了反射

### 优缺点
**优点：** 代码使用更加灵活，为各种框架提供开箱即用的功能提供了方便

**缺点：** 让我们在运行时有了分析类的能力，这增加了安全问题，比如可以无视泛型参数的安全检查(泛型参数的安全检查是在编译时)；
反射的性能稍微差点，但无伤大雅

### 获取类对象的四种方法
1. 知道具体类可以使用，获取类字面量不会触发类的初始化
```java
Class targetClass = TargetClass.class;
```
2. 通过 Class.forName() 传入类的可执行路径进行获取
```java
Class targetClass = Class.forName("cf.carefulhuo.thread.reflection.TargetClass");
```
3. 通过类的实例对象进行获取
```java
TargetClass instance = new TargetClass();
Class targetClass = instance.getClass();
```
4. 通过某个类加载器，传入类的可执行路径进行获取
```java
ClassLoader.getSystemClassLoader().loadClass("cf.carefulhuo.thread.reflection.TargetClass");
```
通过类加载器获取的类，不会进行类的初始化，也就是说静态方法和代码块不会被执行
